## オフライン実装の確認範囲

- Python標準`csv`で解析し、引用符・ヘッダー・列数を検証する。
- `inventory-fictional.csv.txt`をメモリ内に生成する。各値をJSON文字列として記録し、行・列・元行範囲を残す。
- MockのFilesアップロード→属性付きStore登録→一覧・選択・出典→関連付け解除／元ファイル削除を確認した。
- 削除後の再選択拒否・再起動後の削除状態復元を一時SQLiteで確認した。稼働DBをテストに使わない。
- UTF-8とBOM、サイズ・行・列・セル制限、CSRF・Host/Origin・Store許可制御を確認した。

## 実E2Eの事前条件（別途承認が必要）

1. ローカル中継の起動設定、既存SQLiteパス、AWS認証、OpenAIキーの有無を秘密値を表示せず確認する。
2. ローカルの文書Storeと許可リストが既存本番Storeと一致することを確認する。Lambdaにも同じ許可Storeを設定済みであることを確認する。
3. ローカルキーとLambda Secretのキーで同じStoreにアクセスできることを確認する。Models GET成功だけでは証明できない。
4. 最新ローカル中継へ再起動する承認と、架空CSV1件の実登録、索引化状態確認、推論最大1回の承認を得る。既存文書は変更しない。
5. 推論・File Search・ストレージ料金を最新仕様で見積もり、予算枠を確認する。出力上限512、自動再試行なし。料金を見積もれなければ送信前に停止する。

## 登録・検索・出典の検証順序

1. UIから架空CSVを選択し、TXT変換・外部保存の確認後に1回アップロードする。
2. Files IDとStore ID・登録名を秘密値なしの検証台帳へ記録する。応答不明時は再アップロードせず停止して残存を調査する。
3. `personal_llm_document_id=<file_id>`属性を確認し、索引化`completed`まで有限回の状態確認を行う。失敗・タイムアウト時は推論しない。
4. UIでこのファイルだけを選び、空の会話履歴から質問する。
   - 質問例：「確認コードCSV-ALPHA-731に対応する商品の在庫数と商品名を、文書の出典を付けて答えてください。」
   - 質問に正解の37や商品名を含めない。回答は37と対応商品名、出典は記録したfile_idと`inventory-fictional.csv.txt`で照合する。
5. `document_ids`による属性フィルターとAPIの`sources`、UIの出典表示を確認する。検索対象の変更で会話履歴が消去されることを利用し、過去回答からの流用を避ける。
6. HTTP結果・安全な回答・選択ID・出典の一致・推論回数を記録して停止する。文書内容やキーをログへ出さない。

現行APIは回答と抽出済み出典を返し、`file_search_call`や生検索結果・トークン使用量は返さない。
引用の一致と実呼び出しの直接観測は区別する。厳密に実呼び出しを証明する必要がある場合は、
本文を記録しない安全なツール呼び出し診断の設計・別途承認を先に行う。今回はそのコード変更やLambda配備を行わない。

## 削除・後片付け（別途承認が必要）

登録承認だけを削除承認と扱わない。対象file_idと削除範囲を提示し、承認後に実施する。
関連付け解除はSQLiteへ削除開始を保存してから実行し、解除GET 404と再選択拒否を確認する。
元ファイルは変換済みTXTを指し、手元のCSVではない。解除だけではTXTがOpenAIに残る。
現行の実クライアントは他用途不使用を証明できないため、元ファイル削除を安全側に拒否する。
所有者が他用途・対象IDを確認したうえで承認済みの管理操作で削除し、元Files GET 404を確認する。
この手順のために削除制御を解除しない。既存Store自体は削除しない。
台帳に受理と404確認を分けて記録し、未確認なら後片付け完了としない。

## v1.0に残る事項・配備への影響

通常チャット・履歴・文書登録・検索・出典・関連付け解除・再起動後の拒否は成功済み。
元TXTの削除は未実施であり、別途承認が必要。検索内部の実行回数や請求額の直接観測も未実施。
今回のCSV変換・UI対応はローカル中継内で完結する。既存Lambdaは変換済みTXTのfile_idを扱える設計なので、
CSV対応だけを理由にLambda・IAM・Secret・SAMを変更する必要はない。
ローカルSQLiteの削除開始拒否は中継経由のみで保証し、直接Lambda呼び出しとは区別する。
検索はファイル単位であり、行の完全列挙・正確な集計・在庫更新・CSV書き戻しは今回実装しない。
