公開はまだ実施していない。URLは公開後に本人が設定する。職歴・チーム人数・開発時間は推測しない。

## 短い紹介

Python / FastAPIとAWS Lambdaで、個人向けLLMアプリを開発しました。
Backend・推論制御・プロバイダー通信を分離し、会話履歴、OpenAI File Search、出典表示、文書管理を実装しています。
削除要求を外部へ送る前にSQLiteへ状態を保存し、再起動後も検索を拒否する設計に取り組みました。
AIによる実装支援を利用し、自分は要件・制約の整理、構成の採用、環境設定、操作の承認、動作確認を担当しました。
現在のCSV拡張を含むソースはPython 271件・UI 10件のオフラインテストに成功し、
架空データによるAWS経由のチャット・検索・出典・削除制御E2Eも記録しています。

## 技術面接で説明する点

- LLMの回答能力と、認証・許可・入力検証・削除状態というシステム側の責任の違い。
- APIキーの取得権限と、外部APIでキーが有効であることを分けた認証障害の切り分け。
- DELETE受理と反映確認を区別し、未確認状態・明示的再開・再起動を扱ったこと。
- Mock・実API・AWS配備・UI表示の確認を別の証拠として扱ったこと。
- 個人用localhost構成の限界と、公開サービス化に必要な追加認証・可観測性。

数字は[検証記録](verification.md)の条件を併記し、「全機能の完全保証」「本番商用運用実績」等へ拡大しない。
