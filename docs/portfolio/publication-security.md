# 公開コピーのセキュリティ確認

2026-10-18。公開専用ディレクトリに新規Gitを初期化し、元の.git・旧履歴・タグ・remoteをコピーしていない。
元の開発リポジトリの88候補から78ファイルをコピーし、必要な匿名化と資料の再整理を実施した。
元の開発ファイル・Git履歴・AWS・Secret・SQLiteには変更を加えていない。

## 匿名化と除外

- AWS実アカウント番号、実Lambda URL、個人メール、個人の絶対パスを公開ファイルに含めない。
- local_webの固定転送先は`https://example.invalid/chat`。環境変数から任意URLを受け付ける変更はしない。
- 資料中の実Store/File IDを例示IDへ置換。実データ・キー・認証ヘッダー値はコピーしない。
- テスト用のパスは`folder/safe.txt`という疑似入力を使い、出典名のbasename正規化の期待値を維持する。
- コピー元のGit作者情報を継承せず、新しいGit作者は一般名と`portfolio@example.invalid`を使用する。
- 実行台帳、画面画像、SQLite、資格情報、IAM実体、venv、環境別バックアップは候補に含めない。
- 除外した10ファイルと最終公開ファイルは[一覧](publication-file-list.md)を参照。

## 確認方法

公開コピーの全ファイルとコミット対象を対象に、キー形状、AWSアクセスキー、秘密鍵、GitHubトークン、
実アカウント入りARN/ECR、Lambda URL、個人メール、絶対ローカルパス、元の実Store/File IDを検査する。
既知の疑似テスト値・非実在の例示値・公式APIエンドポイントと実環境値を区別する。
Markdown相対リンク、Git差分の空白エラー、追跡ファイル一覧も点検する。
新規Gitのコミット数・親なしコミット・中立的な作者情報・remoteなしを確認する。
元の88ファイルのSHA-256、Git refs・index・変更一覧を事前状態と比較して変更していないことを確認する。

検査は既知パターンとローカル目視確認の範囲であり、未知の秘密値や第三者権利の不存在を完全保証するものではない。
元開発履歴の機密検査結果を公開コピーの履歴検査と混同しない。専門の外部scannerは今回導入していない。

## 実行していないこと

GitHubへのpush・公開設定変更、AWS操作、実OpenAI推論・検索・文書管理、既存DB変更、
元TXT削除、ライセンス新規付与は行っていない。
公開コピーのソースを新たにAWSへ配備できることも検証していない。
