# 第三者著作物・データ・ライセンスの確認範囲

2026-10-18、公開候補のソース・資料・架空データ・ローカル依存メタデータを読み取り確認した。
新しいプロジェクトライセンスは付与していない。LICENSEファイルも新設しない。

## 同梱するもの・しないもの

- 自作アプリとして開発記録のあるPython/JS/HTML/CSS、テスト、Mermaid図、Markdown資料を同梱する。AI支援の利用を明記する。
- ALPHA/BETAの架空TXTと架空在庫CSVのみを同梱する。実ユーザー文書、公開データセット、PDF、画面画像、人物画像、フォント、外部パッケージ本体は同梱しない。
- 外部API資料はリンク参照を維持し、資料本文やSDKソースの複製を追加しない。生成物の完全な外部類似性検査は実施していない。
- 既存ソースの通知・ライセンス表記を削除しない。現在の候補で明示的な外部著作権ヘッダーは見当たらないが、全コードの権利帰属を証明するものではない。
