# 公開版と開発版の関係

2026-10-18。公開専用ディレクトリで新しいGit履歴を作成する。元の履歴・タグ・remote設定はコピーしない。

- 開発側の正式基盤はv1.0。会話・履歴・File Search・文書管理・SQLite削除状態管理を含む。
- CSV対応は開発側でv1.1として別コミットに分離したローカル拡張。公開コピーには両方のソースを含む。
- 開発履歴のコミットIDは参照情報であり、公開Gitのコミットやタグとして解決できない。
- 公開版のlocal_web転送先は非実在の例示URL。OpenAIの固定APIエンドポイントと認証処理は維持する。
- 出典抽出テストの絶対パス形式の疑似入力は、同じbasename正規化を検証する相対パス形式の疑似入力に変更する。
- 資料のStore/File IDは例示値。実環境のID・AWSアカウント・URL・個人パスは含めない。
- 資格情報、SQLite、私的バックアップ、実行台帳、スクリーンショットは配布しない。
- 旧イメージDigest・ランタイムハッシュ・環境別配備コマンドは除外する。公開版が稼働イメージと完全一致するとは扱わない。
- 既存の公開用E2E要約・検証結果は歴史的な記録として残す。今回AWSやOpenAIへ再接続した証拠ではない。

プロジェクト全体への新しいライセンスは付与していない。GitHubへのpush・公開設定変更は別途承認する。
